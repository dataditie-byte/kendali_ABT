# Sistem Pengendalian ABT 2026 — GitHub Pages

Frontend utama sistem berada langsung di:

`index.html`

Tidak menggunakan iframe dan tidak menggunakan `Index.html` Google Apps Script.

Arsitektur:

GitHub Pages (`index.html`)
→ API Google Apps Script (`Code.gs`)
→ Google Sheets

Akses:
- PIC Kegiatan: bebas input
- Tim Pengendali: kode akses `kendali2026`
- Laporan: kode akses `kendali2026`

Deploy folder ini sebagai GitHub Pages.
